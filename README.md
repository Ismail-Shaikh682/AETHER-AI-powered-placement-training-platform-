# AETHER 🚀

## Adaptive Explainable Transformer Framework for AI-Based Skill Assessment, Career Intelligence & Personalized Recommendations

AETHER is an **AI-powered Placement Training Platform** designed to help students prepare for campus placements and internships through a personalized, adaptive, and data-driven learning experience.

The platform brings multiple placement preparation activities into a single system, including **Aptitude, Technical Quizzes, Coding Assessments, AI Mock Interviews, ATS Resume Analysis, Performance Analytics, and Personalized Recommendations**.

AETHER uses modern AI technologies such as **Retrieval-Augmented Generation (RAG), Knowledge Tracing, Adaptive Testing, Abstract Syntax Tree (AST) Analysis, Natural Language Processing (NLP), Large Language Models (LLMs), Speech-to-Text (STT), Text-to-Speech (TTS), and semantic similarity** to analyse user performance and provide meaningful feedback.

## 🔥 Key Innovations

### 1. Retrieval-Augmented Generation (RAG)

AETHER uses RAG to retrieve relevant knowledge and generate **dynamic and company-specific questions**, helping provide fresh and relevant practice instead of relying only on static question banks.

### 2. Knowledge Tracing

The system analyses user performance and learning patterns to estimate **knowledge mastery**, identify skill gaps, and determine areas that require improvement.

### 3. Adaptive Testing (CAT)

Adaptive testing dynamically adjusts the **difficulty of questions according to the user's performance and skill level**, creating a more personalized assessment experience.

### 4. AST-Based Code Analysis

The Coding Module uses **Abstract Syntax Tree (AST) Analysis** along with control-flow and complexity analysis to evaluate code structure, quality, optimization, readability, and maintainability instead of relying only on test-case results.

### 5. AI-Powered Mock Interviews

Large Language Models, NLP, Speech-to-Text, and Text-to-Speech technologies are used to conduct **realistic role-specific mock interviews** and generate detailed performance feedback.

### 6. AI ATS Resume Analysis

The ATS Resume Analyzer evaluates resumes against job descriptions using **keyword matching, semantic similarity, and resume-job description matching techniques** to provide actionable improvement suggestions.
